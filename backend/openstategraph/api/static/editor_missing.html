The server is running fine — this is the one page it can serve without the canvas. You are running from a source checkout, and the editor is a compiled front end that has to be built once.

Build it, then reload this page

npm install
npm run build

That writes dist/ at the repository root, which this server picks up on the next request. No restart needed.

Or run the dev stack instead

./start dev

Vite serves the editor on http://localhost:5273 with hot reload, talking to this API on port 8000.

  • /docs — the API reference
Installing from PyPI instead? pip install "openstategraph[server,ollama]" ships the built editor inside the wheel, so this page never appears there. The provider extra is not decoration: [server] is the web layer and carries no model integration, so without one the editor opens and nothing it draws can run.
