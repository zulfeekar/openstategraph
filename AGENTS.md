# OpenStateGraph — a brief for coding agents

You are working in a project that uses **OpenStateGraph**: a compiler from a
vendor-neutral `workflow.json` to a LangGraph `StateGraph`. This block is
generated by `openstategraph init` and is replaced whole on the next run —
put your own notes outside the markers.

Read this before you write a workflow, a node, a tool or a test. It is short
on purpose; the long form is in the project repository, named at the end.

## 1. What this project is

**We are a compiler, not a runtime.** A document compiles to a standard
LangGraph object that runs anywhere Python runs — importable from a script,
testable with pytest, deployable without the editor.
**Never write an execution engine.** A proposal to "just interpret the graph ourselves" is a
proposal to reimplement checkpointing, `interrupt()`, `Send` fan-out, reducer
merging and streaming; reject it.

Consequences you have to obey when you touch a document:

- **Expressions are a JSON AST, never host-language code.** A router predicate
  is serialisable data. A Python or JavaScript lambda in a document kills
  portability and serialisability in one move.
- **Reducers are a named enum**, not arbitrary functions.
- **The compile seam is one-directional**: `workflow.json` → runtime. Nothing
  reads runtime objects back into the document.
- **A node type id is data**, resolved against a known set. Never invent one.
  If nothing resolves it, the run says so by name — that is the design, not a
  failure to route around.

## 2. The words, and they are not interchangeable

These collide with words used elsewhere in this field. Using the wrong one
produces wrong code, not merely awkward prose.

<!-- lexicon: derived from CLAUDE.md, do not hand-edit -->
- **Graph** = `StateGraph` — nodes, conditional edges, shared state, `Send` fan-out, subgraphs.
- **Loop** = `create_agent` (ReAct). It returns a compiled LangGraph, so it drops into a `StateGraph` as a node.
- Therefore **canvas = StateGraph, Agent node = the loop, workflow composition = subgraphs.**

| User-facing word | Means | Must never mean |
| --- | --- | --- |
| **Revision loop** | grader `revise` → agent `feedback`; ends when the grader passes or the step budget runs out | the agent's internal tool-calling |
| **Step budget** | `recursion_limit` — **supersteps** | "iterations" or "max turns"; one lap with fan-out costs several supersteps |
| **Workflow node** | another workflow run as one isolated step — task in, answer out | inline expansion, shared state |
| **Template** | a starting document; it produces a workflow and stops existing | a node type; a reusable definition |
| **Package** | the reusable definition — `workflows/<slug>/`, the thing a mount points at | a PyPI distribution, in user-facing copy |
| **Instance** | one mount of a package, carrying its own `data.overrides` | a copy of the package |
| **Slug** | a package's folder name — `workflows/<slug>/`, `?w=<slug>`, and what a mount field asks for. **Minted by the backend at first save and frozen**, because a slug that moves renames a directory | a title, a display name, or anything a user chooses or edits |
| **Replay** | reading a recording back — a **profiler**, not a re-execution. Offsets are the server's own `elapsedMs` from stream open; the playhead spends nothing and produces no new run | a re-run; LangGraph's own *replay*, which **re-executes nodes** and fires the model calls again (`/oss/python/langgraph/use-time-travel`, confirmed 2026-08-29). The two words collide exactly where a reader following those docs lands |
| **Re-run** | forking a run from a checkpoint and executing it again — costs model calls, and produces a *different* run. Not built here; if it is ever offered it is a different button, in a different place, with a cost-and-consequences confirmation | a second mode of the play button, or anything the transport does |
| **Eval** | grading a workflow **offline** against a committed dataset of questions whose answers are known — `openstategraph eval`, `<package>/evals/*.eval.json` | the grader node's in-run judgement, which routes rather than scores |
| *(internal only)* the loop | `create_agent` / ReAct | anything in UI copy |

`Package` / `template` / `mount` are the three that get conflated most. The
test a user actually cares about — *if I change the original later, does this
change too?* A **mount** is by reference, so every instance changes. Starting
from a **template** is by copy, so nothing changes; the link was severed.

## 3. Non-negotiables that change what you write

- **TDD. Tests before implementation.** Tests land with — ideally before — the
  change. Never refactor a large class without tests in place first.
- **Interface → Abstract → Base → Concrete.** Every entity family declares this
  ladder — node, edge, tool, provider, workflow — and consumers import the
  interface, never the class. Inheritance must earn itself; where a hierarchy
  exists only to share two fields, use composition and say so.
- **Extend by registering, never by editing the engine.** Every extension point
  is a registry. A new node type, executor, provider, connection rule or
  validation rule must not require touching the core. A registry whose targets
  are left beside it as private methods is the same defect with extra steps.
- **A shared concern is declared once on the abstract base**, never re-declared
  per concrete type — but inherit the *capability* to compose, not the
  composition. Middleware order is a named slot table; any scheme that
  expresses position as one number is expressing something that does not exist.
- **Cardinality belongs to the port, not the node.** There is no node-level
  "multiple edges" flag: it is `maxConnections` on the port descriptor
  (default: in = 1, out = unlimited). Prefer varying the *number* of ports over
  toggling one port's cardinality.
- **Never put a non-finite number in a serialisable field.** `Infinity` and
  `NaN` are not representable in JSON. Use `int | None`, with `None` meaning
  unbounded.
- **A state key more than one node type can write needs a named reducer.** A
  bare scalar is only safe for state exactly one node type ever produces; two
  writers in one superstep raise `InvalidUpdateError` on a field every
  single-writer test passed.
- **A cycle needs a conditional edge**, or it can never terminate. The step
  budget is not a rescue.
- **Read a model's answer tolerantly; trust it strictly.** Accept the shapes a
  model actually produces — the object as well as the string, the reply with no
  fence — and still resolve every candidate against a known set. When the
  prompt and the parser disagree about a format, suspect the parser.
- **Duplication of knowledge is the defect; duplication of shape is often
  fine.** Node configuration is declared once as a field schema; card,
  inspector, defaults and validation all derive from it.

## 4. Building a new thing

Before you build, decide whether it is on the canvas or something on the canvas
uses it, and check the capability exists here rather than assuming it. Ending
with *"this platform cannot do that yet"* and a written-down gap is a correct
outcome, not a failed one — **do not promise what this platform cannot do.**

Then the loop, which is the same one the project uses for itself:

1. **Red, in Python.** Write the test first, against the real thing.
2. **Green.** Implement it.
3. **Red, in TypeScript** — assert the node's *contract*: its id, its fields'
   defaults, its ports.
4. **Green.** Write the definition.
5. **Wire it.** Register it, open the workflow, run it.

Gates: `python -m pytest -q` for the Python half; `npm run verify` if you
touched the editor.

A package is a directory — `workflow.json` beside `tools/`, `functions/`,
`middlewares/`, `tests/`, `knowledge/`, `data/`. Its directory name is its
slug and is frozen. Scaffold one with `openstategraph new <slug>`; copy a
worked one with `openstategraph examples copy <slug>`.

## 6. Things not to do

- **Do not invent a node type id.** Resolve it against what is installed.
- **Do not put host-language code in a document.** Not a lambda, not an import
  path, not a callable — data only.
- **Do not promise a capability this platform does not have.** Say it is not
  there and where the gap is recorded.
- **Do not send a user's graph to a third party.** Diagrams are rendered from
  text produced locally; nothing posts a graph to draw it.
- **Do not label the step budget "iterations" or "max turns"** anywhere a user
  reads. It counts supersteps.
- **Do not pre-fill an editable field with an output contract.** A developer
  supplies rules; the machinery owns the shape of the answer and goes last.
